Read SUMMARY.md first, followed by this file, README.md and PROVENANCE.md.

- Preserve the published source snapshot, original student credits and historical screenshot. Do not restore secrets or omitted personal records from private recovery materials.

- Before committing, reread and synchronize SUMMARY.md and this file. Check Markdown rendering, changed links, image paths, preservation of source/figure bytes and diff scope. Use normal Git publication without rewriting history.
